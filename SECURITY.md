# Security

These scripts can change drivers and system configuration. Compatibility checks, explicit privilege boundaries and recovery paths are part of the supported behavior; please report ways to bypass or break them.

Use [GitHub's private vulnerability reporting](https://github.com/fanks/macbook12-linux/security/advisories/new) if it is available. If that option is unavailable, open an issue requesting a private contact channel without including exploit details or private data.

Do not post passwords, keys, unredacted logs or personal system backups. Only the current `main` branch is maintained; older snapshots may lack fixes.
